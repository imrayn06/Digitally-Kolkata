## 🚀 Overview

**Digitally Kolkata** is a digital agency web platform engineered for high performance, conversion, and brand presence. Built with clean, modern standards to eliminate CMS bloat, achieve sub-second load times, and provide 100/100 Core Web Vitals.

---

## ✨ Features

- **Official Brand Aesthetics:** Deep charcoal & petrol teal background gradient (`linear-gradient(297deg, #1A1A1A 40%, #0F373D 100%)`) with signature marigold gold accents (`#FDB840` / `#E4C82D`).
- **Original Media & Graphics:** Integrated brand logo, `HeroSection.gif` animation, and 3D service graphics.
- **Core Capabilities Breakdown:**
  1. *Branding & Identity*
  2. *UI/UX Human-Centered Design*
  3. *Custom Web Engineering*
  4. *Commercial Product Photography*
  5. *Search Engine Optimization (SEO)*
- **Interactive Project Cost Calculator:** Real-time quote and timeline estimator in Indian Rupees (₹) with dynamic page scope slider and 1-click inquiry prefill.
- **Filterable Case Studies Gallery:** Categorized portfolio with live modals and performance metrics.
- **Instant WhatsApp Lead Redirection:** Functional client inquiry form that formats briefs and opens direct WhatsApp chat (`wa.me`).
- **Complete SEO & Schema:** Semantic HTML5, Open Graph social cards, and Schema.org `ProfessionalService` structured JSON-LD.

## 🛠️ Local Development

To run the site locally:

```bash
# Using npx serve
npx serve -l 3000 .

# Or opening index.html directly in any browser
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploying to `digitallykolkata.online` (Cloudflare Pages)

1. Connect this GitHub repository (`imrayn06/Digitally-Kolkata`) to **Cloudflare Pages** or **Vercel**.
2. Set build command to `(None)` and root directory to `/`.
3. Add custom domain: `digitallykolkata.online`.
4. Free SSL and global edge CDN caching will automatically be active worldwide!
